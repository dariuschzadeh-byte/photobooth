fr-anz photobooth

Daily guide — please keep this next to the booth

Every morning — opening

  1. Switch on the camera. Make sure the power adapter is plugged in (not a battery).
  2. Switch on the flash.
  3. Switch on the printer and check there is enough paper and ribbon.
  4. Switch on the booth PC. The photobooth starts by itself — just wait about one minute.
How do I know it is ready?
The screen shows "enter your code" with the number keypad. That's it — the booth is open.
If the screen does NOT show the keypad
Double-click the icon 1 - START PHOTOBOOTH on the desktop and wait one minute.

Test it before the first guest

1 Type the staff code 731790 on the booth screen.

2 Let it take the 3 photos and print one strip.

3 If a strip comes out and looks good — the booth is ready for guests.

The staff code never runs out. Use it as often as you like. It does not use up a guest voucher.

During the day

What the guest seesWhat it means / what to do
"this code's already been used"The card was already used. Give the guest a new card.
"that code didn't work"Wrong number typed. Ask them to try again slowly.
"oops — something went wrong"Camera or printer problem. The guest's code still works — they can try again. Check: camera on? printer on? paper left? Then let them retype the same code.
Photos are taken, but nothing comes out of the printerThe printer software may have been closed. Double-click 1 - START PHOTOBOOTH — it starts the printer software again. Also check: printer switched on? paper and ribbon left?
Nothing happens / black screenDouble-click 1 - START PHOTOBOOTH on the desktop.
Never close the small window called "fr-anz server"
It usually sits minimized in the taskbar. If it is closed, the booth stops working. If you closed it by accident: double-click 1 - START PHOTOBOOTH.

Evening — closing

  1. Press Alt + F4 to leave the guest screen (or double-click 2 - STOP PHOTOBOOTH).
  2. Switch off camera, flash and printer.
  3. Shut down the PC.

How many vouchers are left?

Open the browser on the booth PC and go to:
localhost:3000/admin

There you can see how many codes are used and how many are left. There is also a "print test strip" button — it prints a test photo strip without using the camera and without using up a voucher. Use it to check the printer.

White lines on the printed strips?
That is the printer, not the software. Tell Dariusch — it usually means the ribbon needs to be re-seated or the print head needs cleaning.
